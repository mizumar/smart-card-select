# 2枚比較機能 仕様書 (CompareBottomSheet)

## 1. 機能概要

気になるクレジットカードを**最大2枚**選んで、スペックだけでなく「年間損益・お得額の試算結果」を並列比較できる機能。
画面下部に常駐する「ボトムバー」と、詳細な試算比較・勝者判定を行う「比較モーダル」の2つのUIで構成される。

---

## 2. できること・提供機能

### 1) 試算結果・お得額のリアルタイム比較（コア機能）

- **年間お得額の自動計算・表示**:
  - ユーザーの利用条件や基本還元率・特典に基づき、2枚のカードそれぞれの「年間見込みお得額（円）」をリアルタイムで試算・表示。
- **勝者判定（Winner）の自動ハイライト**:
  - 試算したお得額が高い方のカードに対して、金額テキストをエメラルドグリーン（`text-emerald-600`）で強調表示。
  - 優位なカードに**「おすすめ！」バッジ（Trophyアイコン）**および **`CheckCircle2`** を付与し、どちらが得かを一目で判断可能にする。
- **試算根拠・注記事項の明確化**:
  - 「※基本還元率での試算。特定店舗や特典によりさらに上振れる場合があります」などの条件・注記（※1, ※2...）を明記し、透明性の高い比較結果を提示。

### 2) カードの選択・上限コントロール

- **2枚までの選定**: 気になるカードを2枚選択して比較リストに追加。
- **上限自動制御**: 2枚選択時は、他のカードの比較ボタンが自動的に無効（`disabled`）化され、3枚目以上の選択をシャットアウト。

### 3) 常駐ボトムバー（スッキリ配置＆背景操作を妨げない）

- **フローティング表示**: 画面下部に浮遊する形で選択中カードをコンパクトに表示。
- **背景のタップ透過**: 最外枠に `pointer-events-none` を設定し、ボトムバー以外のスキマや背景のタップ・スクロール操作を一切妨げない。
- **バッジ表示**: 選択中のカード名をバッジ表示。長い名前は `truncate`（省略表示）で崩れを防止。

### 4) 比較モーダル（ビジュアル＆アクション）

- **キレイなカード画像の並列表示**:
  - クレジットカードの標準比率（`aspect-[1.58/1]`）で表示。
  - フレックススペーサー（`flex-1`）により、左右のカードの高さやレイアウト位置を美しく統一。
- **同時アフィリエイト遷移（2枚同時に開く）**:
  - 各カード単体の「公式サイトへ」ボタン（別タブ開く）。
  - **「両方の公式サイトを別タブで開く」ボタン**: 1枚目を `window.open`（別タブ）、2枚目を `window.location.href`（同タブ）で同時に開くことで、比較後の申し込み体験をシームレス化。

---

## 3. アプリ内での役割・UX上のメリット

- **数値と金額で迷いを解消**: 「結局どっちがいくら得なのか」を具体的な試算金額とおすすめバッジで一発回答する。
- **邪魔にならない常駐UI**: ページ閲覧の邪魔をせず、2枚選んだ瞬間にすぐ比較へ誘導できる。
